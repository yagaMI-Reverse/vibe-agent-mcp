## Честная находка этого прогона

Переформулировка `utp` («каждый заголовок строго до 56 знаков…») не помогла,
а **ухудшила** результат: БРАК вырос 90 → 111 → 153, ГОДНО упало 45 → 32 → 15.
Похоже, генератор не подчиняется текстовым инструкциям о длине символов внутри
`utp` так же надёжно, как обычным содержательным УТП — вероятно, добавленный
текст трактуется как дополнительный контент для заголовков, а не как
мета-инструкция форматирования. Вывод для дальнейшей работы: переформулировку
через `utp` для длины заголовка использовать нельзя; для этого класса дефектов
нужен либо пост-обрезка на стороне агента, либо другой канал управления
генератором (не текстовое поле utp). Подробнее — в `docs/boundaries.md`.
